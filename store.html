Screensaver — GTK4 Screensaver for Linux

A native GTK4/libadwaita screensaver for Linux (Pop!_OS, GNOME, COSMIC), with five modes -- blank, clock, photo slideshow, GLSL shaders, and calm warm-colored random lines that drift across a dark background -- idle detection on both X11 and Wayland, multi-monitor support, and a live-updating preferences window.

A note from the maker: this app was built on Pop!_OS Linux, largely through "vibe coding" (prompting an AI coding assistant rather than hand-typing every line). It's free and open source (GPL-3.0-or-later) -- use it, read it, modify it, integrate it into your own projects, and redistribute it however you like, no restrictions beyond keeping modified redistributions open source too. Since it runs on your machine, please be a courteous user: try it out with your normal backup/update habits, the same as you would with any new software.

How to install it

Clone the repo below, then from a terminal inside it:

# System packages (Debian/Ubuntu/Pop!_OS):
sudo apt install python3-gi gir1.2-gtk-4.0 gir1.2-adw-1 \
    libglib2.0-dev libcairo2-dev python3-dev

git clone https://github.com/ali-kenjo/screen-saving-app-for-linux.git
cd screen-saving-app-for-linux
pip install .
screensaver-app

That registers it as a regular app (with a .desktop entry) and installs the screensaver-app command. Turn on "Launch at login" in its preferences window to have it start automatically, like any other screensaver.

How to use it
  • Open preferences with screensaver-app --preferences, or via the tray icon if your desktop shows one.
  • Pick a mode, set the idle timeout, and turn on session locking -- every change applies live, with a preview in the window.
  • Trigger it immediately with screensaver-app --preview instead of waiting out the idle timeout.
  • Any keyboard or mouse input dismisses it on every monitor at once.
How to modify it locally

Same repo, installed in editable mode instead so your edits take effect immediately:

cd screen-saving-app-for-linux
glib-compile-schemas data/
pip install -e '.[dev]'
screensaver-app

Every screensaver mode is a small self-contained class under screensaver_app/modes/ -- copy an existing one to build your own. Full details, the project layout, and the test suite are documented in the bundled README.md.
